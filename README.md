# 英汉练习本

支持 Excel 导入、英汉双向词句练习的静态网页，默认包含 310 条词句。

网页地址：https://english-practice-private-20261026.stable-jam-6022.chatgpt.site/

## 使用

- 看中文拼写英文，填写后提交判对错；留空提交可直接显示答案。
- 看英文时，点击显示答案查看中文释义。
- 点击上一题可返回，保留本轮的答案、判定和未提交的输入；不会重复计分。
- 电脑按回车提交或显示答案，再按回车切换下一题。拼写题自动聚焦输入框。
- 手机不自动聚焦输入框，点击输入框后可输入。
- 可导入 `.xlsx` 文件的第一个工作表，前两列需为英文和中文。也可清空或恢复默认题库。

## 本地运行

使用 Python 在此目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:8765/ 。网页无需安装依赖或构建。

导入的 Excel 文件在浏览器内读取，不会上传。默认题库包含用户提供的词句；原文疑似笔误暂按来源保留。

此私人仓库保存网页源码。当前网页托管于上述私人 Site，仓库本身未启用 GitHub Pages。
